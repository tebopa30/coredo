# Security Policy for coredo_app

## Supported Versions
We provide security updates only for the following versions:

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ |
| 0.x     | ❌ |

## Reporting a Vulnerability
If you discover a security vulnerability in **coredo_app**:

- **Do not open a public issue.**
- Please report privately via email: **tebopa30@gmail.com**
- Include the following details:
  - Steps to reproduce
  - Affected platform (iOS / Android)
  - Flutter/Dart version used
  - Potential impact (e.g., data leak, unauthorized access)
  - If related to external services (OpenAI API, AdMob), include usage details

We will:
- Acknowledge your report within **3 business days**
- Investigate and provide updates on progress
- Release a patch after disclosure
- We do **not** provide public credit to reporters

## Disclosure Policy
- Vulnerabilities will be disclosed publicly first, and then fixed in subsequent releases.
- We ask reporters to keep details private until disclosure.
- After resolution, we may publish a security advisory for transparency.

## Additional Notes
- This project uses **OpenAI API** and **Google AdMob**. Vulnerabilities related to these integrations should also be reported.
- Please specify the **Flutter/Dart version** when reporting issues.
